使用方法：1. 上传 Excel 数据文件（需含「姓名」「单位」「职务」列）；2. 上传 PPTX/DOCX 模板（至少一个）；3. 点击生成并下载。
模板规范：在模板文本框中填写以下占位符，程序会自动替换为 Excel 中对应列的内容。
支持双大括号 {% raw %}{{姓名}}{% endraw %} 或单大括号 {% raw %}{姓名}{% endraw %} 两种格式。
示例：「尊敬的 {% raw %}{{姓名}}{% endraw %} {% raw %}{{职务}}{% endraw %}」，替换后生成「尊敬的 张三 总经理」。
提示：所有处理均在服务器内完成，支持 Docker 一键部署。
Web 端入口：web_app.py，Docker：Dockerfile。
